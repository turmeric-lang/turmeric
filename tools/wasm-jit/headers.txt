# tools/wasm-jit/headers.txt -- the system headers the browser JIT module
# embeds for c2mir (wasm-jit-plan 5.4).  One name per line; '#' starts a
# comment.  build-module.sh embeds the transitive closure of these inside
# Emscripten's musl sysroot (emcc -M -nostdinc against it), at /sysinclude.
#
# The list is every C11 standard header, plus every POSIX header the emitted
# C of the fixture corpus includes (2026-10-28: an `emit-c` over all of
# tests/fixtures/, Windows and Apple headers left out -- they sit under
# #ifdef).  c2mir supplies its own stdbool, stdint, stddef, stdarg, limits,
# float, iso646, stdalign and stdnoreturn and reads those first; listing them
# costs nothing.  A program that includes a header missing here fails to
# compile with c2mir's "error in opening file", and the page falls back to the
# interpreter; add the header here when that is a header a program should have.

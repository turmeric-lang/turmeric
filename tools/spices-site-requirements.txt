# markdown 3.10 is the pin rather than the newest: it is the earliest release

# package, two digests, no conditional edges.  Needs Python >= 3.10; CI pins
# 3.12 where it sets up Python at all.

#   python3 -c "import urllib.request,json; d=json.load(urllib.request.urlopen('https://pypi.org/pypi/markdown/<ver>/json')); [print(f['digests']['sha256'], f['filename']) for f in d['urls']]"

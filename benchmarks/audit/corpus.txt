# Performance-audit corpus (docs/upcoming/performance-audit-plan.md, WP0).
#
# Read by benchmarks/audit/run-corpus.py.  One program per line:
#
#   <path>  <engines>  <check>  [timeout=<s>]  # note
#
# engines  comma list of cc, jit, interp.  A program with user inline C is
#          cc,jit only: the interpreter does not run inline C (run-turi.sh
#          skips such programs for the same reason).
# check    `exact`; or, for self-timing programs, `cols=N,M,...` (compare only
#          those comma-separated columns of each line) or `keep-lines=P:N,M`
#          (compare only lines N, M of every group of P).
#
# Pins live in benchmarks/audit/expected/ (a fixture's pin is its own
# expected.stdout).  Turmeric programs only: performance-comparison/ is not in
# the corpus.  Not in it, and why:
#
#   benchmarks/bench-capture-restore.tur   SX0(a)'s sweep; > 120 s, owned by run-capture-curve.sh
#   examples/guestbook/src/main.tur        an HTTP server; never exits
#   examples/snake/src/main.tur            needs raylib and a display
#   examples/guestbook/src/{conts,handlers,httpd,router,security,store,strutil,templates}.tur,
#   examples/snake/src/raylib.tur          library modules: build, print nothing
